# 開支票

一個簡潔、易用嘅香港支票列印工具。喺瀏覽器填日期、抬頭、銀碼，中文銀碼會自動轉大寫，對好位就可以一次過列印多張。

網頁係靜態嘅，資料同對位設定只留喺你部電腦，唔會上傳到伺服器。

正式網址（GitHub Pages）：

**https://henma8888.github.io/print-cheque/**

第一次打開要有網絡；之後同一個瀏覽器可以離線再用。

## 點用

1. 打開上面個網址，或者自己喺電腦跑（見下面「本機開啟」）。
2. 喺「支票」頁加列：日期、抬頭、銀碼。中文銀碼會自動出現，唔啱可以自己改。
3. 日期只需打數字，唔使斜線，例如 `25102026`；印出嚟會變成 `25/10/2026`。
4. 可以匯入 Excel 或文字：
   - Excel 欄位可以係「日期、抬頭、銀碼」，或者「日、月、年、抬頭、銀碼」。
   - 文字每行例如：`25/10/2026：陳大文：1234.50`
5. 撳大大個「列印」掣，一次過印晒表入面嘅支票。

## 列印設定

喺瀏覽器列印對話框：

- 紙張選 **A5 橫向**（或你喺「對位」揀嘅 DL／C5 信封、支票原尺寸）
- 縮放選 **實際大小**（Actual size），唔好選「適合頁面」
- 邊界設為 **無**（None / 0）
- **關掉頁首頁尾**（Headers and footers），以免印到網址同頁碼
- 將支票放喺紙嘅**右邊**，對齊右邊同預設上邊距

Chrome／Edge 最穩陣。第一次建議用空白紙試印一張，對好位再印真正支票。

## 對位

第二個分頁「對位」用嚟校位置，唔會阻住開支票：

- 預覽入面有淡格線（唔會印出），可以拖動日期、抬頭、中文銀碼、數字銀碼
- 數字銀碼可以單獨拉上拉下
- 紙張預設：A5 橫向、DL 信封、C5 信封、支票原尺寸
- 支票預設 17 cm × 8.9 cm，可以改；亦可調上／右／左邊距同字級、欄寬
- 可以上傳支票相片做對位底圖（唔會印出），再填實測闊同高
- 如果版面超出紙張，會有提示
- 設定會自動記喺呢部電腦。換第二部就「匯出設定」，再開「讀取設定」

## 中文銀碼

自動用大寫數字：零壹貳參肆伍陸柒捌玖，單位：拾佰仟萬億、元、角、分，結尾加「正」。

例子：

- `0` → 零元正
- `1234.50` → 壹仟貳佰參拾肆元伍角正
- `1000.05` → 壹仟元零伍分正

銀碼可以寫 `1234.50`、`$1,234.50` 或 `HK$1,234.50`。

## 本機開啟

需要 [Node.js](https://nodejs.org/) 18 或以上。

```bash
git clone https://github.com/henma8888/print-cheque.git
cd print-cheque
npm install
npm test
npm run dev
```

瀏覽器打開終端機顯示嘅本機網址即可。要產出靜態檔：

```bash
npm run build
npm run preview
```

`dist/` 就可以放到任何靜態網站空間。

## 私隱

支票內容唔會送到任何伺服器。對位設定用呢部瀏覽器嘅 localStorage 保存。本專案冇帳戶、冇雲同步。
